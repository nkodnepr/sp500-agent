# Stock Agent — инструкция пользователя

Полное руководство по работе с программой: что она умеет, как запустить,
как читать результаты анализа и на что обращать внимание.

---

## Что это за программа

Stock Agent — аналитический агент по акциям США. Он не покупает и не
продаёт акции сам, а анализирует выбранные компании и даёт рекомендации
**BUY / SELL / HOLD** (покупать / продавать / держать) с конкретными
ценовыми ориентирами и уровнями риска — на основе технического анализа,
фундаментальных показателей компании, новостного фона и общего состояния
рынка.

Программа доступна в двух вариантах — оба используют один и тот же
"движок" анализа, просто разный интерфейс:

| | **Настольное приложение** | **Telegram-бот** |
|---|---|---|
| Когда удобнее | Работаете за компьютером, нужен визуальный интерфейс | Хотите получать сигналы на телефон без открытия ничего специально |
| Установка | Запустить `StockAgent-Setup.exe` (Windows) — как обычную программу | Нужен деплой на сервер (Render или свой) |
| Автоматические уведомления | Нет — запускаете вручную, когда нужно | Да, ежедневно по расписанию |
| Скрининг всех 500 компаний S&P 500 | Да, отдельная вкладка | Нет (только вручную добавленные тикеры) |

# ЧАСТЬ 1. Настольное приложение

## Установка и запуск

### Windows: обычная установка (ничего заранее ставить не нужно)

1. Запустите файл **`StockAgent-Setup.exe`** двойным кликом.
2. **Скорее всего появится синее окно «Система Windows защитила ваш
   компьютер».** Это нормально и не означает вирус: так Windows
   реагирует на любую программу без платной подписи разработчика.
   Нажмите **«Подробнее»**, затем кнопку **«Выполнить в любом случае»**.
3. Дальше обычный установщик: «Далее» → «Установить» → «Завершить».
   Права администратора не нужны, пароль система не спросит.
4. Готово: ярлык **Stock Agent** появится на рабочем столе и в меню Пуск.

Python, командная строка и распаковка архивов для этого не нужны —
всё необходимое уже внутри программы.

**Первый запуск и первый анализ идут дольше обычного** (до минуты на
акцию): программа обучает модели прогноза. Дальше результаты берутся из
кэша и появляются быстрее.

**Как удалить:** «Параметры» → «Приложения» → найти «Stock Agent» →
«Удалить». Ваш список акций при этом сохранится (см. ниже) — если
установите программу заново, он вернётся.

**Где хранятся ваши данные:** список отслеживания и обученные модели
лежат в папке `%LOCALAPPDATA%\StockAgent` — отдельно от самой программы.
Поэтому удаление или обновление программы их не стирает. Чтобы перенести
всё на другой компьютер, скопируйте эту папку туда же.

### Windows: версия без установки

Если устанавливать нежелательно (например, на рабочем компьютере) —
есть `StockAgent.exe`: скопируйте его куда угодно и запускайте двойным
кликом. Предупреждение Windows обходится так же, как в пункте 2 выше.

### macOS и Linux

Двойной клик по **`run_macos.command`** (на Linux — команда
`bash run_macos.command` в терминале). При первом запуске программа сама
создаст рабочее окружение и установит всё необходимое — нужно только
подключение к интернету и установленный Python.

**Вручную (любая ОС):**
```bash
pip install -r requirements-desktop.txt
python desktop_app.py
```

## Обзор окна программы

### Левая панель — список отслеживания (watchlist)

- Поле ввода внизу — впишите тикер (например `AAPL`, `TSLA`, `NVDA`) и
  нажмите **«Добавить»** или Enter. Программа проверит, что тикер
  реально существует, прежде чем добавить
- **«Удалить выбранный»** — убирает выделенный тикер из списка
- **«Анализ выбранного»** — полный разбор по одной акции (или просто
  дважды кликните по тикеру в списке)
- **«Сканировать весь список»** — прогоняет весь watchlist разом
- **«Переобучить все модели»** — принудительно обновляет модели прямо
  сейчас (обычно происходит само раз в неделю)
- **«Скрининг S&P 500 →»** — переключает на вкладку сканирования всего
  индекса

### Вкладка «Анализ»

Самая подробная вкладка. Показывает по выбранной акции:

- **Прогноз цены на 4 горизонта**: 1 неделя, 2 недели, 1 месяц, 3 месяца.
  Каждый — не одно число, а диапазон цены (например «$196–$204»), плюс
  ожидаемая доходность в % и уверенность модели
- **Ключевые факторы** — на основе чего модель приняла решение
  (например: моментум за 60 дней, положение цены относительно 200-дневной
  средней) — чтобы прогноз не был «чёрным ящиком»
- **Фундаментал** — рост выручки год к году, чистая маржа, ROE, долг/капитал
- **Рынок (S&P 500)** — бычий / медвежий / боковой рынок в целом; влияет
  на итоговую рекомендацию (например, покупка против медвежьего рынка
  требует более сильного согласия сигналов)
- **Новостной фон** — если включён sentiment-анализ (см. ниже)
- **Итоговая рекомендация**: 🟢 BUY / 🔴 SELL / ⚪ HOLD, с объяснением причины
- **Уровни риска** (только для BUY/SELL) — стоп-лосс, тейк-профит,
  соотношение риск/прибыль, рекомендуемый размер позиции

### Вкладка «Скан списка»

Прогоняет весь watchlist одним нажатием и показывает таблицей только
акции с реальным сигналом (BUY/SELL) — без лишнего шума от HOLD.
Удобно как ежедневная рутина.

### Вкладка «S&P 500»

Скрининг всего индекса (~500 компаний), не только вашего списка.
Работает в два этапа (честно, а не одним махом — полный анализ 500
компаний занял бы часы):

1. **Быстрый технический отбор** по всем ~500 компаниям сразу (несколько
   минут) — простой скор по моментуму, RSI, положению относительно
   скользящих средних, без обучения модели
2. **Полный анализ** (тот же, что во вкладке «Анализ») — только для
   top-N самых «бычьих» и top-N самых «медвежьих» кандидатов по итогам
   первого этапа. Число N настраивается прямо на вкладке

Если список компаний S&P 500 не удалось загрузить (нет интернета) —
используется сокращённый резервный список, и программа честно
предупреждает об этом жёлтым текстом.

### Вкладка «Бэктест»

Введите тикер → «Запустить бэктест». Проверяет, обыграла бы стратегия
простое «купил и держи» за последние ~3 года. **Обязательно проверяйте
это перед тем, как доверять сигналам по конкретной акции** — если
стратегия проигрывает бенчмарку, сигналам по этому тикеру пока не стоит
доверять реальными деньгами.

### Вкладка «Честная точность»

Сверяет прошлые сигналы (накопленные из «Анализа» и «Скана») с тем, что
случилось на самом деле. Показывает % верных прогнозов по каждому
горизонту и практическую эффективность BUY/SELL. Данные появляются не
сразу — нужно, чтобы прошло время после сигналов (неделя для недельного
прогноза, 3 месяца для квартального).

# ЧАСТЬ 2. Telegram-бот

## Установка

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен
2. `cp .env.example .env`, впишите `TELEGRAM_TOKEN`
3. **Рекомендуется:** узнайте свой Telegram user_id через
   [@userinfobot](https://t.me/userinfobot) и впишите в
   `ALLOWED_TELEGRAM_USER_IDS` — иначе бот отвечает любому, кто его найдёт
4. `pip install -r requirements.txt && python telegram_bot.py` — или
   задеплойте на Render (см. README, раздел «Деплой через GitHub и Render»)

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и список команд |
| `/add AAPL` | Добавить тикер в список отслеживания |
| `/remove AAPL` | Убрать тикер |
| `/list` | Показать список |
| `/check AAPL` | Разовый полный анализ прямо сейчас |
| `/history` | Последние 10 отправленных сигналов |
| `/backtest AAPL` | Проверка стратегии на истории (~3 года) |
| `/accuracy` | Честная точность прошлых сигналов |
| `/retrain AAPL` | Принудительно переобучить модель |

Дальше бот сам, по расписанию (по умолчанию 9:30 утра, настраивается в
`.env`), присылает сигналы BUY/SELL по вашему watchlist — писать для
этого ничего не нужно.

# ЧАСТЬ 3. Как понимать результаты анализа

## Что означает диапазон цены

```
1 месяц: ↑ $203.00–$214.60 (+6.5%, увер. 65%)
```

Это **статистическая оценка на основе истории**, а не гарантированное
предсказание будущего. Диапазон построен на том, насколько сильно
разбегались похожие движения у этой акции в прошлом — если раньше было
много волатильности, диапазон шире.

## Что означает BUY / SELL / HOLD

- **BUY** — минимум 3 из 4 горизонтов согласованно указывают на рост,
  уверенность модели выше порога
- **SELL** — то же самое, но на падение
- **HOLD** — сигналы противоречивы, уверенность низкая, или контекст
  (резко негативные новости, медвежий рынок) идёт вразрез с техническим
  сигналом — в этом случае программа намеренно ничего не рекомендует,
  а не гадает

## Уровни риска

- **Стоп-лосс** — цена, при достижении которой стоит выйти из позиции,
  чтобы ограничить убыток (рассчитан на основе волатильности акции — ATR)
- **Тейк-профит** — целевая цена фиксации прибыли
- **Риск/прибыль** — например «1:1.7» значит, что потенциальная прибыль
  в 1.7 раза больше потенциального риска
- **Размер позиции** — рекомендация, сколько акций купить, чтобы риск
  на одну сделку не превышал 1% капитала (условного — вы указываете
  сумму сами при желании)

## «Самообучение»

Модели переобучаются автоматически на свежих данных, когда кэш
устаревает (по умолчанию раз в неделю) — не нужно ничего делать
специально, но при желании можно запустить переобучение вручную
(кнопка в приложении / команда `/retrain` в боте).

# Главное правило использования

Внизу каждого анализа есть предупреждение не для галочки: диапазоны
цены и уровни риска — статистическая оценка, а не гарантия. Программа
создана как **помощник в принятии решения**, а не как автопилот:

1. Перед тем как довериться сигналам по конкретной акции — прогоните
   **бэктест** на этой акции
2. Со временем сверяйтесь с вкладкой **«Честная точность»** — она
   покажет, насколько прогнозы реально сбываются, а не насколько модель
   в себе «уверена»
3. Используйте рекомендацию как один из факторов решения, а не
   единственный источник истины
